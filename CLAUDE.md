# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Deklara: a validation-phase landing site plus the self-hosted lead-capture and
analytics stack behind it. The product itself (compiling messy crypto records
into a Swiss `Wertschriftenverzeichnis`) is **not built** — the project is
testing demand first. `docs/project-brief.md` is the source of truth for what
is being validated and the thresholds that decide build-or-stop.

```
web/      static site, deployed to GitHub Pages
server/   Node API on the Mac mini, reached via Cloudflare Tunnel
scripts/  build-legal.py — generates the six legal pages
docs/     brief, build plan, campaign spec, research findings
```

## Commands

```bash
# server/ (no runtime dependencies — node:sqlite, node:http, node:test only)
npm start                     # foreground on :8787
npm test                      # 30 tests
npm run install-service       # (re)install the launchd agents
npm run backup                # run nightly maintenance by hand
npm run logs                  # tail logs/api.log

# a single test
node --no-warnings --test --test-name-pattern='rate limits' 'test/**/*.test.js'

# seed demo traffic into a scratch DB (refuses to run without DB_PATH)
DB_PATH=/tmp/demo.db node test/seed.js

# regenerate the legal pages after editing scripts/build-legal.py
python3 scripts/build-legal.py
```

`--no-warnings` is not cosmetic: `node:sqlite` is still flagged experimental and
prints to stderr on every start.

## This repository controls live infrastructure

`kryptodeklara.ch` is live and collecting real signups. Pushing to `main`
deploys the site within a minute. The API runs as a launchd agent on this very
machine — editing `server/src/` and restarting affects production immediately.
There is no staging environment.

## Architecture

Two deployment targets, coupled by one hostname:

- **`web/`** → GitHub Pages on push to `main` (workflow filters on `web/**`).
  Static files only, no build step.
- **`server/`** → `ch.kryptodeklara.api` launchd agent on the Mac mini, bound to
  `127.0.0.1:8787`, exposed as `api.kryptodeklara.ch` through
  `ch.kryptodeklara.tunnel` (cloudflared).

The browser loads the site from GitHub's CDN and posts to the Mac mini. Both
sides must agree on the contract in `web/tracker.js` and the form handler at the
bottom of each `web/*/index.html`.

Data model is multi-tenant from the start (`projects.key`), so future projects
reuse this server rather than standing up another.

## Invariants that are easy to break

**Adding a route to `server.js` does not make it public.** The tunnel only
forwards paths matching its ingress regex — currently `/submit`, `/event`,
`/health`, and `/admin*`. A new endpoint returns 404 from the internet while
working perfectly on localhost. Update the tunnel config via the Cloudflare API
(see `docs/dashboard-access.md`).

**The three locale files must keep byte-identical `<style>` blocks.** Verify
after any CSS change:

```bash
cd web && for f in index.html en/index.html fr/index.html; do \
  sed -n '/<style>/,/<\/style>/p' "$f" | md5 -q; done
```

**Never edit the legal HTML directly.** `web/{impressum,datenschutz}.html`,
`web/fr/{mentions-legales,confidentialite}.html` and
`web/en/{legal-notice,privacy}.html` are generated by `scripts/build-legal.py`,
which asserts equal section counts across languages. Hand-editing one language
reintroduces exactly the drift the generator exists to prevent.

**`web/datenschutz.html` and its translations are a legal statement, not
documentation.** They describe precisely what the code collects, how the
visitor hash works, and the retention periods. Changing what is collected, or
`EVENT_RETENTION_DAYS`, means editing `scripts/build-legal.py` in the same
commit.

**Analytics beacons must be `text/plain`.** `application/json` is not
CORS-safelisted, so it forces a preflight `sendBeacon` cannot perform; Chrome
drops the request silently while `sendBeacon` still returns `true`. The server
parses JSON regardless of declared content type.

**Honeypot field names must match on both sides.** The pages render `company`;
`server/src/spam.js` accepts several names. A mismatch silently disables the
trap and the tests are written per field name for that reason.

## Privacy model

No cookies, no raw IPs stored. A visitor is
`SHA-256(daily_salt + ip + user_agent)`, the salt being random, memory-only and
rotated at 00:00 UTC — so hashes stop being linkable across days. Query strings
are stripped from paths and referrers before storage. This is what keeps the
site free of a consent banner, and it is asserted in the published policy.

## Auth

- `/admin` and `/admin/leads.csv` sit behind **Cloudflare Access** (one-time
  email code to the owner) *and* a bearer token from
  `server/data/admin-token.txt`, generated on first boot at mode 600.
- Locally, `http://localhost:8787/admin?token=...` bypasses Access by design.

## Operational gotchas

- Node is **nvm-managed**, so its absolute path contains the version number.
  The launchd plists embed that path — re-run `npm run install-service` after
  any node upgrade or the service dies silently.
- LaunchAgents run **only while the user is logged in**. An unattended reboot
  leaves everything down until someone logs in.
- Submissions during downtime are **lost, not queued** — a documented, accepted
  risk for the discovery phase.
- The shell here is **zsh**, which does not word-split unquoted variables.
  `R="--resolve host:443:1.2.3.4"; curl $R` passes one argument, not two.
- Local DNS caches negative lookups. If `curl` cannot resolve a hostname that
  `dig` resolves fine, that is why — test with `--resolve` against the edge IP.
